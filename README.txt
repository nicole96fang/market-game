小镇杂货铺 · 3D经营版 V5

启动方式：
1. 解压 ZIP。
2. 将 index.html 上传到 GitHub 仓库根目录，或部署到 Vercel / Netlify / GitHub Pages。
3. 打开部署网址即可游玩。首次加载需要网络连接 Three.js CDN。

V5 新增：
- 小镇批发市场：按商品成本自选数量采购，5件为一档，结算前检查钱包余额。
- 小镇委托板：每日两项委托（订单数、营业额），完成后领取 RM45 和 4 点人气。
- 委托完成状态随每日结算重置，并自动保存。
- 保留此前 3D 店铺、顾客、库存、售价/货架管理、升级、天气、每日目标与自动保存功能。

提示：
- 游戏进度保存在当前浏览器的 LocalStorage。请勿清除该网站的数据，否则本机存档会被删除。
- Three.js 从 CDN 加载，首次进入需要网络。
- 建议在较新的 Chrome、Edge 或 Safari 中游玩。
