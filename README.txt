小镇杂货铺 · 3D经营版 V6

V6 新增：
- 每日经营账簿：查看今日营业额、商品毛利、成交订单、流失顾客，以及最近30天的结算记录。
- 顾客类型：普通顾客、常客、VIP 顾客；VIP 更偏好价格较高的商品。
- 顾客成交会统计商品毛利（售价减商品成本）；营业额与现金收入分开记录。
- 缺货顾客会计入流失数量，并影响少量人气。
- 每日打烊自动归档当日账单，历史记录自动保存。

包含此前版本功能：
3D 店铺、顾客、库存与商品管理、批发采购、每日委托、店铺升级、天气切换、每日目标、自动补货。

启动方式：
解压后将 index.html 上传到 GitHub 仓库根目录，或部署到 Vercel / Netlify / GitHub Pages。
首次加载需联网从 CDN 加载 Three.js。存档保存在当前浏览器 LocalStorage，请勿清除网站数据。
