小镇杂货铺 · 3D 经营版 V4

本版包含：
- Three.js 实时 3D 杂货店，支持鼠标/触控旋转与缩放。
- 顾客进店、逛货架、选择商品、柜台结账。
- 6 类商品库存、售价、进货成本、库存扣减。
- 商品管理：修改售价、选择摆放货架。
- 库存管理：单品补货 +5、快速补货每类 +2。
- 店铺升级：扩店、货架升级、装饰升级与人气提升。
- 每日营业额、订单数、金币、人气、打烊结算。
- 每日目标：卖出 5 件商品可领取 RM30 和 3 点人气奖励。
- 天气场景切换：晴天、微雨、傍晚。
- 点击 3D 商品模型可查看实时库存和售价。
- 自动保存：库存、资金、店铺等级、装饰、天气和每日进度。
- 页面切到后台或离开时会额外保存一次。

运行：
解压后部署到 GitHub Pages / Vercel / Netlify。首次运行需联网加载 Three.js CDN。
手机可手指拖动旋转、双指缩放；电脑可鼠标拖动和滚轮缩放。
存档保存在当前浏览器 LocalStorage，清除网站数据会删除存档。
